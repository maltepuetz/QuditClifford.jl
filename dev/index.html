What is QuditClifford.jl? ​

QuditClifford.jl simulates qubit and qudit Clifford circuits with stabilizer tableaux, for any prime local dimension d and for pure and mixed stabilizer states. It covers Clifford unitaries and uniformly random Cliffords, projective Pauli measurements, exact expectation values, dephasing, trace-out and reset channels, entanglement entropy, negativity and the information measures, and exact or dense expansions of small states for debugging.

Development status

QuditClifford.jl is under active development and has not yet reached a stable release. APIs may change before version 1.0.

Quick start ​

Install QuditClifford with

julia
using Pkg
Pkg.add("QuditClifford")

then prepare an entangled pair of qutrits, measure one of them, and watch the entanglement disappear:

julia
julia> using QuditClifford

julia> state = DestabilizerTableau(3, 2; state = :product);  # two qutrits in |00⟩

julia> apply!(state, Fourier(1)); apply!(state, SUM(1, 2));  # entangle them

julia> entanglement_entropy(state, [1])  # in units of log 3
1

julia> t = measure!(state, SinglePauli(1, 0, 1));  # Z on qutrit 1: random t ∈ 0:2

julia> measure!(state, SinglePauli(2, 0, 1)) == t  # qutrit 2 now gives the same outcome
true

julia> entanglement_entropy(state, [1])
0
